# 09-Quality exercise solution

Three practical risks are partial writes, accidental loss of the file, and concurrent writers. A first local runbook can require one process at a time and backups made while writes are stopped. It must still acknowledge that direct file overwrite is not crash-safe.

A stronger storage implementation may use database transactions. Its guarantees must be tested and documented; calling it a repository does not create them.

Plaintext titles are acceptable only for data and access conditions the learner accepts. Moving to shared hosting changes the security review. Authentication establishes who a user is; authorization decides which tasks they can access.

A measurable performance report includes task count, machine, build mode, timing method, and observed results. A target is not a measurement.
