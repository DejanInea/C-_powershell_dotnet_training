## First release

List three essential user actions. Name the input and observable result of each.

## Acceptance criteria

For each action: Given [starting state], when [action], then [observable result].
Include invalid input, missing data, restart, and a failure case.

## Quality goals

Name a measurable target, test environment, and measurement method.
Examples: maximum task count, response time, acceptable data loss.

## Constraints and scope

Team size, operating systems, offline/network needs, budget, delivery time.
Explicitly defer features that do not support this release.

## Unknowns
