# Reusable design documents

Copy these files into your own project's docs folder and replace the prompts with decisions and evidence. An unanswered question is useful if it is clearly marked.

- [Requirements.md](Requirements.md): users, boundaries, behaviors, constraints.
- [Architecture.md](Architecture.md): structure, dependencies, runtime flow, data.
- [ADR.md](ADR.md): one important decision and its tradeoffs.
- [Test-Plan.md](Test-Plan.md): examples that demonstrate correctness.
- [Runbook.md](Runbook.md): build, configuration, release, recovery.

Write a few clear sentences per section. Update documents when decisions change.
