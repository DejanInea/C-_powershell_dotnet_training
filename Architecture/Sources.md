## Existing architecture PDF

The course already includes [Microsoft's ASP.NET Core architecture ebook](../DotNet10/Official-References/Microsoft-ASPNetCore-Architecture-Ebook.pdf), cataloged in the [.NET reference index](../DotNet10/Official-References/README.md). It is broader and more advanced than these lessons. Read its architecture principles and common application architecture sections after you can explain our example.

The ebook includes earlier-generation framework examples. Use the current Microsoft docs for API syntax and version-specific behavior.

## How to study a difficult page

Pick one term. Define it in your own words, draw one picture, locate one example in this repository, and write a counterexample. Return to the source to check what your simplification omitted. Do not memorize a pattern without knowing what problem would justify it.
