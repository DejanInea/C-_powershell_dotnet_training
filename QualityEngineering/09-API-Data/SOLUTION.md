# 09-API-Data suggested solution

Valid creation returns 201 with a positive integer ID, the normalized title, and isComplete=false. Invalid input should not add tasks; the lab verifies stored collection size as well as status for relevant cases.

Restart evidence uses a new server process reading the same file. It demonstrates persistence for that sequence, not abrupt-power-loss durability.

The lab does not measure concurrent throughput, browser behavior, ownership, or backup restoration. Read its raw results and environment metadata before writing a release summary.
