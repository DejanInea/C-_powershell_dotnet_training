# 10-UI-Quality suggested solution

Keyboard navigation and screen-reader feedback require an actual UI, so they are proposed-scope checks here. A browser receiving JSON is not that UI.

Performance needs a workload and target before timing results can mean success or failure. Record dataset, machine, build mode, concurrency, and measurement method.

An ownership test requires agreed users and authorization rules. The local teaching API has none; it should not be recommended as a public shared service based on its functional checks.
