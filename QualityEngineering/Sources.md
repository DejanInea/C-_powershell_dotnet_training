# Primary sources and further study

This is original course material prepared on 16 October 2026. Tool instructions should be checked against the current official documentation when you install or configure a tool.

| Source | Useful topic |
| --- | --- |
| [ISTQB Foundation Level overview and syllabus](https://istqb.org/certifications/certified-tester-foundation-level-ctfl-v4-0/) | Vocabulary and structured further study; certification is optional |
| [draw.io](https://www.drawio.com/) | Editable flow and state diagrams |
| [LibreOffice](https://www.libreoffice.org/) | Optional desktop spreadsheet suite |
| [GitHub Projects](https://docs.github.com/en/issues/planning-and-tracking-with-projects/learning-about-projects/about-projects) | Optional team tables and boards |
| [Postman collection runs](https://learning.postman.com/latest-v-12/docs/collections/running-collections/running-collections-overview) | Saved API checks and result review |
| [Chrome DevTools Network](https://developer.chrome.com/docs/devtools/network/) | Observe HTTP requests and responses |
| [Playwright UI mode](https://playwright.dev/docs/test-ui-mode) | Visual browser-test execution |
| [Playwright Trace Viewer](https://playwright.dev/docs/trace-viewer-intro) | Replay evidence of browser interactions |
| [W3C accessibility easy checks](https://www.w3.org/WAI/test-evaluate/preliminary/) | An initial accessibility review, not full conformance evidence |
| [OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/) | Later structured security study on an appropriate test environment |

The risk scales, example defect workflow, and release gates in this folder are course conventions. They are not presented as mandated ISTQB or industry-wide rules.

The practice target is the repository's existing local API. Use the code and [worked contract](Worked-Example/Contract.md) to establish exact expected behavior. The API has no user interface or identity model; browser/accessibility/ownership exercises are clearly marked as proposed future scope.
