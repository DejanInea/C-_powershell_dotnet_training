# Reusable QE templates

Copy these into your own project/evidence folder and replace prompts with specific facts.

- [Test strategy](Test-Strategy.md): scope, risks, approach, environments, and decision criteria.
- [Worst-case table](Worst-Case-Table.csv): empty CSV header for your own scenario table.
- [Test case](Test-Case.md): inputs, steps, expected result, actual evidence.
- [Exploratory charter](Exploratory-Charter.md): a timeboxed learning mission.
- [Bug report](Bug-Report.md): a reproducible observation with user impact.
- [Investigation and fix](Investigation-and-Fix.md): hypotheses, options, retest, regression.
- [Release summary](Release-Summary.md): evidence, gaps, residual risk, recommendation.

Keep facts, hypotheses, and proposed requirements visibly separate. Empty evidence means unexecuted/unknown, not passed.
